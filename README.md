# Financial Analyzer (المحلل المالي)

برنامج تحليل مالي بواجهة ويب محلية (Streamlit): رفع ملفات Excel، إدخال بيانات الشركات، تحليل، مقارنة، وتصدير تقارير Excel و PDF.

## التشغيل (VS Code)
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
streamlit run app.py
```
يتطلب Python 3.10 أو أحدث. للتأكد من سلامة الكود: `python tests/smoke_test.py`

## طريقة الاستخدام
1. **إدارة الشركات** ← حمّل القالب، املأ الخلايا الزرقاء، ثم ارفعه (أو أدخل البيانات يدوياً، أو جرّب البيانات التجريبية).
2. **تحليل شركة** ← قائمة الدخل (رأسي/أفقي/هوامش)، الميزانية، النسب.
3. **مقارنة شركات** ← جدول مقارنة لسنة محددة + تطور أي مؤشر عبر السنوات.
4. **التقارير** ← تحميل Excel و PDF لشركة واحدة أو لمقارنة.

البيانات المحفوظة تُخزَّن في `data/companies/` (ملف JSON لكل شركة).

## هيكل المشروع
| الملف | الدور |
|---|---|
| `app.py` | الواجهة |
| `src/schema.py` | تعريف بنود القوائم (مصدر واحد لكل الأجزاء) |
| `src/template.py` / `src/loader.py` | إنشاء قالب Excel / قراءته |
| `src/income_analysis.py` | الجزء 1: قائمة الدخل |
| `src/balance_analysis.py` | الجزء 2: الميزانية |
| `src/ratios.py` | الجزء 4: النسب المالية (المجموعة الأساسية) |
| `src/compare.py` | مقارنة الشركات |
| `src/reports.py` | تصدير Excel و PDF |
| `src/samples.py` | شركتان تجريبيتان (أرقام وهمية) |

## قادم
- الجزء 3: قائمة التدفقات النقدية (من الميزانيتين وقائمة الدخل)
- الجزء 5: الأسهم، التنبؤ، والتقييم (DCF) + نسب السوق (P/E وغيرها)
